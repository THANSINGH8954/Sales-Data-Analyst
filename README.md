# 📊 Sales Performance Analysis Dashboard

Analyze a retail sales dataset end-to-end — cleaning, exploratory analysis, KPIs,
an interactive dashboard, and a stakeholder-ready PDF report — to answer the
questions a sales leader actually asks: *What's driving revenue? Which products
and regions matter most? Are we growing? Where should we focus next?*

## 🧭 Project overview

**Task:** analyze a real-world-style sales dataset to identify sales trends,
top-performing products, customer purchasing behavior, and revenue growth,
then present the findings as an interactive dashboard for decision-making.

**Requirements covered:**
- ✅ Data Cleaning & Preprocessing
- ✅ Exploratory Data Analysis (EDA)
- ✅ KPI Analysis
- ✅ Interactive Dashboard
- ✅ Business Insights

> **About the data:** this repo ships with a synthetic-but-realistic
> two-year retail sales dataset ([`data/sales_data_raw.csv`](data/sales_data_raw.csv),
> ~10.5K rows) generated by [`scripts/generate_data.py`](scripts/generate_data.py).
> It's deliberately seeded with the kind of messiness real sales exports have —
> duplicate rows, missing values, inconsistent text casing, mixed date formats,
> return/cancellation rows — so the cleaning step in the notebook has genuine
> work to do. **Drop in your own sales export with the same column names to
> analyze real data** — everything downstream (EDA, KPIs, dashboard, report)
> will work unchanged.

## 🖥️ The interactive dashboard

The dashboard (`dashboard/app.py`) is built with **Streamlit** + **Plotly** and
lets you filter by date range, region, category, and customer segment while
exploring:

- **Trends** — monthly revenue/profit, order volume, day-of-week seasonality
- **Products & Categories** — revenue by category, top 10 products, discount-vs-margin analysis
- **Customers** — segment mix, purchase-frequency (loyalty) distribution, top 10 customers
- **Regions** — revenue by region/country, revenue by shipping mode
- **Raw Data** — a filterable, downloadable view of the underlying cleaned data

It reads directly from `outputs/cleaned_sales_data.csv`, so it always reflects
whatever the notebook (or `scripts/run_analysis.py`) most recently produced.

> **Why Streamlit instead of a `.pbix`/`.twbx` file?** Power BI and Tableau
> workbooks are binary, platform-specific files that most reviewers can't open
> without a paid desktop install. A Streamlit app is source code any Python
> user can run with one command on any OS, which fits the brief of *"any
> person can run [it]."* The cleaned CSV in `outputs/` is also formatted so you
> can load it directly into Power BI / Tableau / Excel if you prefer those
> tools — see [Using with Power BI or Tableau](#using-with-power-bi-or-tableau).

## 🚀 Getting started

### 1. Clone and install dependencies

```bash
git clone https://github.com/<your-username>/sales-performance-dashboard.git
cd sales-performance-dashboard

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

Requires **Python 3.10+**.

### 2. (Optional) Regenerate the sample dataset

The raw dataset is already included, but you can regenerate a fresh random
sample at any time:

```bash
python scripts/generate_data.py
```

### 3. Run the analysis pipeline

This cleans the data, runs EDA, computes KPIs, and writes everything the
dashboard and report need into `outputs/`:

```bash
python scripts/run_analysis.py
```

Or, for the full narrative walkthrough with explanations, open the notebook:

```bash
jupyter notebook notebooks/sales_analysis.ipynb
```
*(Run All Cells — the notebook writes the same files as `run_analysis.py`.)*

### 4. Launch the interactive dashboard

```bash
streamlit run dashboard/app.py
```

Then open the URL Streamlit prints (usually `http://localhost:8501`) in your
browser.

### 5. (Optional) Regenerate the PDF report

```bash
python scripts/build_report.py
```

This reads `outputs/kpis.json`, `outputs/insights.json`, and the chart images
in `outputs/figures/` and produces
`outputs/reports/Business_Insights_Report.pdf`.

## 🔎 Using your own data

Replace `data/sales_data_raw.csv` with your own export using these columns
(rename/map your columns to match):

| Column | Type | Description |
|---|---|---|
| `OrderID` | string | Unique order identifier |
| `OrderDate` | date | Date the order was placed |
| `ShipDate` | date | Date the order shipped |
| `ShipMode` | string | Shipping method |
| `CustomerID` | string | Unique customer identifier |
| `CustomerName` | string | Customer name |
| `Segment` | string | Customer segment (e.g. Consumer, Corporate) |
| `Region` / `Country` | string | Geography |
| `ProductID` / `ProductName` / `Category` | string | Product info |
| `Quantity` | int | Units ordered (negative = return/cancellation) |
| `UnitPrice` | float | Price per unit |
| `Discount` | float | Discount applied (0–1) |
| `Sales` | float | Line-item revenue |
| `Profit` | float | Line-item profit |

Then re-run steps 3–5 above.

### Using with Power BI or Tableau

If you'd like to build a Power BI/Tableau workbook on top of this analysis
instead of (or alongside) the Streamlit dashboard, point either tool at
`outputs/cleaned_sales_data.csv` — it's a flat, analysis-ready table with all
engineered fields (order month/quarter, day of week, profit margin, return
flag, outlier flag, etc.) already computed.

## 🛠️ Methodology summary

**Data Cleaning & Preprocessing**
- Standardized text fields (trimmed whitespace, consistent title-casing)
- Parsed mixed date formats into proper `datetime` values
- Removed exact duplicate rows
- Imputed missing values using business rules (e.g. `Region` re-derived from
  `Country`, missing `Discount` treated as 0%) rather than blindly
  dropping rows
- Flagged (rather than deleted) returns/cancellations and statistical outliers,
  since both are legitimate business signal, not noise
- Engineered analysis-ready fields: order month/quarter, day of week,
  shipping delay, profit margin

**Exploratory Data Analysis**
- Revenue/profit trend over time, with visible seasonality
- Revenue by category, product, region, segment, and shipping mode
- Discount level vs. profit margin relationship
- Order volume by day of week
- Customer purchase-frequency distribution

**KPI Analysis**
- Total revenue, profit, and margin
- Order count, customer count, average order value, units sold
- Month-over-month and year-over-year revenue growth
- Repeat customer rate and return rate

**Business Insights**
- Translated into plain-English, decision-ready recommendations in the
  [PDF report](outputs/reports/Business_Insights_Report.pdf) — covering
  discount strategy, category/region investment priorities, retention,
  demand-driven staffing/promotions, and product concentration risk.
